# LLM Server Calculator 🧮

Клиентский веб-калькулятор для расчёта требований к железу при локальном инференсе LLM без бэкенда. Работает полностью в браузере.

## ✨ Особенности

- **Два режима работы**:
  - **Режим A** ("От железа к модели"): задёте GPU, получаете список моделей, которые помещаются
  - **Режим B** ("От модели к железу"): задаёте модель, получаете три конфигурации (MIN/OPTIMAL/MAX)

- **Расчётное ядро**: реализовано чистыми функциями на TypeScript (§4)
- **Полностью клиентский**: нет бэкенда, нет внешних API, все данные в JSON-файлах
- **Без секретов**: можно безопасно деплоить на GitHub Pages
- **Версионированные каталоги**: GPU, модели, квантизации с метаданными о сборах

## 📦 Установка и запуск локально

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

# Сборка для продакшена
npm run build

# Проверка типов
npm run typecheck

# Линт
npm run lint

# Тесты
npm test
```

## 🚀 Деплой на GitHub Pages

1. **Установите gh-pages**: `npm install -g gh-pages`
2. **Добавьте в package.json**:
   ```json
   "scripts": {
     "deploy": "gh-pages -d dist"
   }
   ```
3. **Настройте GitHub**: Settings → Pages → source: main branch, folder: `/dist`

## 📊 Каталог данных

Данные для расчётов хранятся в `data/`:

- `gpus.json` — GPU (15+ позиций, consumer/prosumer/datacenter)
- `models.json` — модели LLM (25+ включая MoE)
- `quantizations.json` — методы квантизации (FP16/F8/Q4-Q8 и др.)
- `engines.json` — инференс-движки (vLLM/llama.cpp/TGI/SGLang)
- `cpus.json` — CPU платформы для рекомендаций
